# VariMitra - Wari Seva Technology

## Map Coordinates Note
Some coordinates in the Wari routes data (`wari-2025-locations.json`) are marked with `coordinate_confidence: "approximate"`. These represent general village or town centroids rather than the exact halt ground. 

For future refinement, you can use a free geocoding API like OpenStreetMap Nominatim. Please see `meta.recommended_geocode_refinement` in the JSON data for more details on refining these coordinates before production use.
